# Publishing Seva Hifi

The complete source is in [Sugarlicks/SevaHifi_website](https://github.com/Sugarlicks/SevaHifi_website). This is a static site with no install or build step.

To publish with GitHub Pages, open the repository’s Settings, choose Pages, and select deployment from the `main` branch and repository root. Use GitHub’s returned site URL to check both the homepage and `epk/`.

Configure the custom domain `sevahifi.com` separately when ready, following the current GitHub Pages custom-domain instructions. Preserve existing email DNS records when changing web hosting.

The EPK uses noindex metadata and a robots.txt exclusion. Share its direct link with industry contacts. Listening enquiries use sugarlicks@protonmail.com; the supplied SoundCloud profile is also linked.

For future edits, change the source files in this repository. Keep the artist photographs in the existing Baz, Gmuva, Levani order. See CONTENT-TBC.md for the remaining optional content.
